# האתר שלי

הפרויקט של הקורס סטרטאפיסטים. כאן נבנה את האתר שלכם עם Next.js ו-Claude Code.

## איך מתחילים

1. לוחצים **Use this template**, ואז **Create a new repository**, בשם `my-site`
2. במאגר החדש: **Code**, ואז **Codespaces**, ואז **Create codespace on main**
3. כשה-Codespace מוכן, כותבים בטרמינל:

```
npm run dev
```

4. לוחצים **Open in Browser**, ורואים את האתר

## מה יש בפרויקט

| קובץ | מה הוא עושה |
|---|---|
| `app/page.tsx` | דף הבית |
| `app/layout.tsx` | המסגרת שעוטפת את כל הדפים |
| `app/globals.css` | העיצוב: צבעים, גופן וגדלים |
| `components/LikeButton.tsx` | רכיב: כפתור, ומה קורה כשלוחצים עליו |

לא בטוחים מה קובץ עושה? שואלים את Claude: "מה הקובץ הזה עושה?"

## לפני שיוצאים

עוצרים את ה-Codespace: github.com/codespaces, שלוש הנקודות, **Stop codespace**.
